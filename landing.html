核心功能

一个平台，覆盖设备全生命周期

从设备激活入网到固件远程升级，从实时监控到告警处置，11 个模块协同工作，告别多系统切换。

设备管理

设备激活、心跳在线检测、状态机管理。支持首次激活自动入网，故障状态不被掩盖，离线自动补推升级任务。

在线状态心跳检测状态机

产品管理

按产品维度组织设备，统一固件归属与设备分类。同一产品下的设备共享升级策略，批量管理更高效。

产品建模设备分组

固件管理

固件上传、版本管理、发布控制。仅下发已发布版本且取最高版本，自带版本比较防降级，支持鉴权下载与静态直链双地址。

版本控制防降级鉴权下载

OTA 远程升级

SSE 长连接主动推送 + 轮询补推双保险。离线设备上线自动补推，支持失败重试、任务暂停、设备级明细追踪与结果上报。

SSE 推送离线补推任务追踪

告警中心

设备离线、OTA 失败等异常自动生成告警，按严重程度分级。实时掌握设备健康状态，快速定位处置。

分级告警实时通知

仪表盘

设备总数、在线分布、固件版本占比、告警趋势一目了然。ECharts 可视化，运维态势实时掌握。

数据概览ECharts

接入指南

设备侧接入文档与示例一站式提供。HMAC Token 鉴权流程清晰，嵌入式端按真实 HTTP 状态码处理。

接入文档设备鉴权

API 统计

接口调用量、错误率、热门路由与方法分布实时统计。Redis 加速 O(1) 读取，降级 SQLite 兜底。

调用量错误率路由分布

系统管理

可视化系统配置，敏感项脱敏显示。支持 Redis 连接、Token TTL、注册开关等热更新配置，多实例共享。

配置管理热更新

用户管理

用户增删改、分组分配、状态管控。PBKDF2 12 万次迭代加密口令，登录失败统一文案防枚举。

用户管理PBKDF2

用户组权限

18 个权限点的 RBAC 体系，权限点改用户组即时生效。内置三组：超管 / 运维 / 只读，支持提权防护与末位超管保护。

RBAC即时生效提权防护

核心优势

为什么选择它

不是因为功能多，而是因为每一项都经得起生产环境检验。

01

企业级鉴权

无状态 HMAC Token + 18 权限点 RBAC。改用户组权限即时生效，提权防护与末位超管保护齐备，前后端共用同一份权限定义。

02

可靠 OTA

SSE 主动推送 + 轮询补推双保险，离线设备上线自动补推。失败设备可重置重试，任务状态机精准追踪到每一台设备。

03

实时推送

SSE 长连接毫秒级下发升级指令。多实例部署通过 Redis Pub/Sub 跨进程广播，单点连接表也能全局触达。

04

弹性扩展

Redis 可选接入，连接失败自动降级不阻塞启动。单机 SQLite 零依赖开箱即用，多实例配 Redis 即可水平扩展。
